      Kết nối GitHub

      Cách tạo token
      1. Mở GitHub → Fine-grained tokens → Generate new token.
      2. Repository access: Only select repositories → chọn repo của site này.
      3. Permissions → Repository permissions → Contents: Read and write.
      4. Tạo token, copy và dán vào ô trên. Không chia sẻ token cho ai.

      Token chỉ được gửi tới api.github.com. Nếu không tick "Ghi nhớ", token sẽ mất khi đóng tab.
